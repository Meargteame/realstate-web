## Your Role: AGENT

### ✅ What You CAN Do:

```
✓ Create property listings
✓ Manage your listings
✓ View and respond to leads
✓ Track opportunities
✓ Manage contacts
✓ View your dashboard
✓ Update your profile
✓ Access agent tools
```

### ❌ What You CANNOT Do:

```
✗ Access admin panel
✗ Manage other agents
✗ View all system properties
✗ Change system settings
✗ Manage user accounts
✗ Access system-wide analytics
```

---

## Role Comparison

### AGENT (Your Role)
```
Dashboard: Your metrics only
Listings: Your properties only
Leads: Your leads only
Access: Agent Command Center
```

### ADMIN (If you were admin)
```
Dashboard: System-wide metrics
Listings: All properties
Leads: All leads
Access: Admin Panel + Agent Center
```

### USER (Public users)
```
Dashboard: None (public site only)
Listings: Can browse, not create
Leads: Can submit inquiries
Access: Public website only
```

## Quick Actions

### 1. Create Your First Listing
```
Click: [Create Listing] button (top right, red)
Fill in: Property details, photos, price
Result: Listing appears in "Your Active Listings"
```

### 2. Add a Lead
```
Click: "Contacts / Leads" in sidebar
Click: "Add New Lead" button
Fill in: Contact information
Result: Lead appears in "Recent Lead Activity"
```

### 3. Create an Opportunity
```
Click: "Opportunities" in sidebar
Click: "Create Opportunity"
Select: A lead or contact
Result: Opportunity appears in "Sales Pipeline"
```

## Need Help?

**Dashboard empty?**
→ Normal for new accounts. Start by creating a listing.

**Role not showing?**
→ Refresh browser (F5) or clear cache (Ctrl+Shift+R)

**Can't create listings?**
→ Make sure backend is running on port 5000

**Wrong role displayed?**
→ Contact admin to update your role in the database
