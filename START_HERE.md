## 🚀 Quick Actions

### 1. Test Locally (5 minutes)
```bash
# Backend
cd backend
npm install
npm start

# Frontend (new terminal)
cd frontend
npm install
npm run dev
```

Visit: http://localhost:3001

### 2. Fix Map Feature (2 minutes)
The map works but needs a real Mapbox token:

1. Go to https://account.mapbox.com/ (FREE signup)
2. Copy your token
3. Add to `frontend/.env`:
   ```
   VITE_MAPBOX_ACCESS_TOKEN=pk.your_real_token_here
   ```
4. Restart frontend

## 🐛 Common Issues

### Map not showing?
→ Get Mapbox token (see above)

### Can't connect to database?
→ Check `backend/.env` has correct DATABASE_URL

### CORS errors?
→ Add frontend URL to ALLOWED_ORIGINS in backend

### Build fails?
→ Run `npm install` in both backend and frontend
