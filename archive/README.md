# Archive

Historical artifacts moved out of the repo root to reduce clutter. Nothing here
is referenced by the application, build, or deploy scripts — it's kept only for
reference and can be deleted if no longer useful.

- `docs/` — status/summary/planning markdown files from earlier development
  sessions (phase completions, deployment notes, analyses, etc.).
- `scripts/` — ad-hoc `test-*`, `check-*`, `fix-*`, `quick-*`, `verify-*` scripts,
  their `.txt` output captures, and screenshot PNGs used during manual testing.

These were moved (not rewritten), so `git log --follow <file>` still shows full
history.
