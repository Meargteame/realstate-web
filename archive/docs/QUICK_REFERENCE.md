## 🚀 Deploy Steps

1. **Backend to Railway** (10 min)
   - Sign up at railway.app
   - Deploy from GitHub
   - Add PostgreSQL
   - Set environment variables

2. **Frontend to Vercel** (5 min)
   - Sign up at vercel.com
   - Import GitHub repo
   - Set root to `frontend`
   - Add environment variables

3. **Update CORS** (2 min)
   - Add frontend URL to backend

4. **Test** (5 min)
   - Visit your Vercel URL
   - Test all features

5. **Share with client!** 🎉
